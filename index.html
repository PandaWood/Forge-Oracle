How this works

Each item and target level has its own saved seed in your character file. An attempt turns that seed into one roll between 0 and 1, then stores a new seed. Reloading cannot change the outcome, so the next results can be read ahead of time.

Seeds are written only when the game saves, so quit to the main menu after any attempt before dropping the file here. Predictions were checked against 14 real attempts on Valheim 1.0.20 with the wood idol. The exact success cutoff is known only to lie between roughly 0.55 and 0.66, which is why that band is marked unclear.

The list is in order. Attempt 1 is what happens on your next upgrade of this item, attempt 2 is the one after that, and so on. A success moves the item up a level, which has its own list, so check the new level after each success. A failure breaks the item, and the next copy you upgrade at the same level gets the next attempt on the list.
