How this works

Each item and target level has its own saved seed in your character file. An attempt turns that seed into one roll between 0 and 1, then stores a new seed. Reloading cannot change the outcome, so the next results can be read ahead of time.

Seeds are written only when the game saves, so quit to the main menu after any attempt before dropping the file here. Predictions were checked against 14 real attempts on Valheim 1.0.20. An upgrade succeeds when the roll is 0.65 or less. That value, and the fact that every failure destroys the item, comes from the game data as read by Melichor's ValheimSaveParser, and it fits every attempt we recorded.

Each row is one upgrade step for a single item. Row 1 takes it from its current level up one, row 2 takes it up another, and so on. Each level has its own saved seed, so each row uses the next roll for that level. The rows after the first assume every earlier step succeeded, because a failure breaks the item. If a step breaks it, the rows after it do not apply to that item.
